### 2. Autonomous Enterprise Runtime (`autonomous-enterprise-runtime`)
* **Role/Contribution**: Author & Principal Architect
* **Description**: An operating-system-grade runtime infrastructure for autonomous enterprise AI agent networks, bridging the gap between simple workflow orchestration and reliable production deployments.
* **Key Components**:
  * **Runtime Scheduler**: Priority queues with policy validations (cost, tool permissions) and self-healing recovery handlers.
  * **Coordination Bus**: Decentralized pub-sub event bus for secure, audited agent-to-agent interactions.
  * **Cognitive Memory Systems**: Working cache, episodic experience logs, and shared blackboards with mutex locks.
  * **Economic Routing**: Cost-aware engine matching task complexity to optimal LLMs within budget caps.
  * **Observability & Governance**: Decision-level telemetry and compliance audit replay.
* **Tech Stack**: Python, Event-driven architecture, SQLite/VectorDB.

### 3. Agentic System Failure Playbook (`agentic-system-failure-playbook`)
* **Role/Contribution**: Author & Principal Architect
* **Description**: A code-first engineering playbook for containing, detecting, and recovering from autonomous AI agent failures in production.
* **Key Components**:
  * **Failure Taxonomy**: Schemas classifying reasoning drift, tool-use loops, and context pollution.
  * **Reversible Autonomy**: Action journaling enabling transaction rollbacks and compensating operations.
  * **Decision Traceability**: High-fidelity reasoning trace serialization for forensic auditability.
* **Tech Stack**: Python, JSON Schema validation, Telemetry tracing.

### 4. Agentic Analytics Platform (`spot`)
* **Role/Contribution**: Author & Lead Developer
* **Description**: A governed Six-Layer Runtime decision system for enterprise analytics, separating the reasoning Data Plane from the policy Control Plane.
* **Key Components**:
  * **Six-Layer Runtime**: Perception, Memory, Planning, Action, Control, and Governance.
  * **Universal Control Plane**: Query interceptors enforcing semantic safety and cost constraints.
  * **Self-Healing ReAct Loop**: Auto-corrects data query exceptions iteratively.
* **Tech Stack**: Python, SQL, AWS-ready Infrastructure, LangChain/LlamaIndex.

### 5. Production RAG Pipeline (`RAG`)
* **Role/Contribution**: Author & Developer
* **Description**: Asynchronous enterprise RAG pipeline with hallucination evaluation.
* **Key Components**:
  * **Async Ingestion**: Inngest workflow orchestration for proxy polling and retry queues.
  * **Vector Indexing**: Qdrant + LlamaIndex + local embeddings.
  * **LLM-as-a-Judge**: Groq Llama 3.3 faithfulness evaluation to detect hallucinations.
* **Tech Stack**: FastAPI, Inngest, LlamaIndex, Qdrant, Groq (Llama 3.3), Streamlit.

### 6. Computer Vision Behavioral Analytics (`yolox`, `yolo`)
