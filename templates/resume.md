## GITHUB ENTERPRISE & OPEN SOURCE AI PROJECTS
### 1. Autonomous Enterprise Runtime (`autonomous-enterprise-runtime`)
* **Role/Contribution**: Author & Principal Architect
* **Description**: An operating-system-grade runtime infrastructure pattern for autonomous enterprise AI agent networks. Specially designed to bridge the gap between simple workflow orchestration and reliable production deployments.
* **Key Components**:
  * **Runtime Scheduler**: Task scheduling priority queues, policy validations (rate-limiting, cost, tool permissions), and self-healing recovery handlers (retries, exponential backoffs, LLM fallbacks, and human escalation).
  * **Coordination Bus**: A decentralized pub-sub event bus enabling secure, audited agent-to-agent interactions.
  * **Memory Systems**: A multi-layered cognitive memory architecture implementing working memory caches, episodic experience logs, and shared blackboards with mutex locks.
  * **Economic Routing**: Cost-aware routing engine that analyzes task complexity to dynamically match tasks with optimal LLMs, enforcing reasoning budget limits.
  * **Observability & Governance**: High-fidelity decision-level telemetry collection and compliance auditing for compliance replay.
* **Tech Stack**: Python, Event-driven architecture, SQLite/VectorDB simulation.

### 2. Agentic System Failure Playbook (`agentic-system-failure-playbook`)
* **Role/Contribution**: Author & Principal Architect
* **Description**: A comprehensive handbook and engineering repository detailing practical failure modes of autonomous AI agents in production, along with defensive containment, detection, and recovery patterns.
* **Key Components**:
  * **Failure Taxonomy**: Architectural validation frameworks to identify and prevent reasoning drift, tool-use loops, and context pollution.
  * **Reversible Autonomy**: Action journaling systems enabling rollbacks and compensating transactions for autonomous writes or transactions.
  * **Decision Traceability**: High-fidelity reasoning trace serialization for forensically auditing agent decision-making pathways.
* **Tech Stack**: Python, JSON Schema validation, Telemetry tracing.

### 3. Agentic Analytics Platform (`spot`)
* **Role/Contribution**: Author & Lead Developer
* **Description**: A production-grade Agentic Decision System designed to bridge the "Autonomy-Trust Gap" in enterprise analytics. Separates the reasoning Data Plane from the policy Control Plane.
* **Key Components**:
  * **Six-Layer Runtime**: Implements explicit layers for Perception, Memory, Planning, Action, Control, and Governance.
  * **Universal Control Plane**: Intercepts queries to enforce semantic safety boundary checks and cost constraints.
  * **Self-Healing ReAct Loop**: Automatically detects data query exceptions and executes iterative self-correction.
* **Tech Stack**: Python, SQL, AWS-ready Infrastructure, LangChain/LlamaIndex.

### 4. Production Retrieval-Augmented Generation Pipeline (`RAG`)
* **Role/Contribution**: Author & Developer
* **Description**: An enterprise-grade, asynchronous RAG pipeline combining high-performance document parsing, semantic search, and real-time hallucination evaluation.
* **Key Components**:
  * **Asynchronous Ingestion**: Integrates Inngest workflow orchestration for proxy polling and task queue management.
  * **Vector Indexing**: Employs Qdrant vector database (running in Docker) combined with LlamaIndex and local embeddings.
  * **Faithfulness Evaluation**: Integrates an LLM-as-a-Judge validation step using Llama 3.3 via Groq API to evaluate context faithfulness.
* **Tech Stack**: FastAPI, Inngest, LlamaIndex, Qdrant, Groq (Llama 3.3), Streamlit (Dark Glassmorphism UI).
